# Components

We don't re-document component APIs. This page is an index of the [shadcn/ui](https://ui.shadcn.com/docs/components) primitives installed in this project — each entry links out to the official docs for props, variants, and accessibility notes.

Browse the full catalog at [ui.shadcn.com/docs/components](https://ui.shadcn.com/docs/components). If a primitive is missing here, add it — don't build your own.
