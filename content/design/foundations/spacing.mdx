# Spacing

## Rules

1. **Use Tailwind's 4px scale.** Stick to the common rungs (2, 4, 6, 8, 12). Half-steps need a reason.
2. **Gap, not margin, for flex/grid children.** Margin is for prose flow only.
3. **Pick the rung by scope.** Wider scope → bigger rung. See the ladder below.

## The four ranks

Each rank is a scope. Step **one rung up** the ladder as you open a wider container, one rung down as you nest inward.

| Rank | Rung | Typical utility | Example |
|---|---|---|---|
| **Page** | 12 (48px) | `space-y-12`, `mt-12` | Between major page sections. |
| **Card / panel** | 6 (24px) | `p-6`, `gap-6` | Inner padding of a card; rhythm between its header, body, footer. |
| **Fields** | 4 (16px) | `space-y-4`, `gap-4` | Between form fields or list rows inside a card. |
| **Inline** | 2 (8px) | `gap-2` | Icon → label inside a button, chip, menu item. |

## Mobile

On screens narrower than `sm` (640px), the two outer ranks step down one rung. Fields and Inline don't change — they follow text size, not screen width.

| Rank | Desktop | Mobile | Tailwind |
|---|---|---|---|
| **Page** | 48px (rung 12) | **32px (rung 8)** | `space-y-8 sm:space-y-12` |
| **Card / panel** | 24px (rung 6) | **16px (rung 4)** | `p-4 sm:p-6` |
| **Fields** | 16px (rung 4) | 16px (rung 4) | `space-y-4` |
| **Inline** | 8px (rung 2) | 8px (rung 2) | `gap-2` |

## Inline rung in a dropdown

Inside menus, items don't get rung-4 gaps between them — that's too loose. Stay at rung 2: tight item padding (`px-2 py-1.5`), `gap-2` between icon and label, and let the hover/selected background — not whitespace — separate items.

## Example: building a shadcn card

The shadcn `Card` already bakes in rung 6 — `gap-6` on the card, `px-6` on header/content/footer. Your job is just to apply rung 4 between form fields and rung 2 on inline children. Do not override the card's padding.

<div className="not-prose my-6 max-w-md">
  <Card>
    <CardHeader>
      <CardTitle>Create organization</CardTitle>
      <CardDescription>
        Organizations group users, funds, and requests.
      </CardDescription>
    </CardHeader>
    <CardContent>
      <div className="space-y-4">
        <div className="space-y-2">
          <Label htmlFor="demo-name">Name</Label>
          <Input id="demo-name" placeholder="Acme Ops" />
        </div>
        <div className="space-y-2">
          <Label htmlFor="demo-code">Short code</Label>
          <Input id="demo-code" placeholder="acme-ops" />
        </div>
      </div>
    </CardContent>
    <CardFooter className="justify-end gap-2">
      <Button variant="outline">Cancel</Button>
      <Button><Plus />Create</Button>
    </CardFooter>
  </Card>
</div>

```tsx
import { Button } from "@/components/ui/button"
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from "@/components/ui/card"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import { Plus } from "lucide-react"

export function CreateOrgCard() {
  return (
    <Card>
      {/* rung 6: Card owns header/content/footer spacing via gap-6 + px-6 */}
      <CardHeader>
        <CardTitle>Create organization</CardTitle>
        <CardDescription>
          Organizations group users, funds, and requests.
        </CardDescription>
      </CardHeader>

      <CardContent>
        {/* rung 4: space between form fields */}
        <div className="space-y-4">
          <div className="space-y-2">
            <Label htmlFor="name">Name</Label>
            <Input id="name" placeholder="Acme Ops" />
          </div>
          <div className="space-y-2">
            <Label htmlFor="code">Short code</Label>
            <Input id="code" placeholder="acme-ops" />
          </div>
        </div>
      </CardContent>

      <CardFooter className="justify-end gap-2">
        {/* rung 2: inline gap between button icon and label, and between buttons */}
        <Button variant="outline">Cancel</Button>
        <Button><Plus />Create</Button>
      </CardFooter>
    </Card>
  )
}
```
