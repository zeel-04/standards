# Design System

A house design system built on **shadcn/ui** + **Tailwind v4**. Opinionated defaults for colour, radius, typography, and patterns.

## How to read it

- **Rules block** at the top of each page — numbered, terse. Scan this.
- **Prose + examples** below — the why and the do's/don'ts.

For component APIs and accessibility, we defer to the [shadcn/ui docs](https://ui.shadcn.com/). This site only covers **what we've customised**.
